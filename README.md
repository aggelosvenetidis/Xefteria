# Ξεφτέρια — ανέβασμα στο Render (όπως η Γνωσιομαχία)

1. Ανέβασε τα αρχεία αυτού του φακέλου σε ένα GitHub repo.
2. Render → New → Web Service → διάλεξε το repo.
3. Build Command: (κενό)   ·   Start Command: `node server.js`
4. Άνοιξε τη διεύθυνση που θα σου δώσει. Ο σύνδεσμος πρόσκλησης έχει τη μορφή `…/?room=ABCD`.

Τοπικά: `node server.js` και άνοιξε http://localhost:3000 (δεν χρειάζεται npm install).

Νέες ερωτήσεις: πρόσθεσέ τες στο `questions.js`, πάντα στο ΤΕΛΟΣ της κατηγορίας.
